System ​

Piqs.Dicke Type
julia
Dicke(N; hamiltonian=nothing, emission=0.0, dephasing=0.0, pumping=0.0,
      collective_emission=0.0, collective_dephasing=0.0, collective_pumping=0.0)

The Dicke structure which builds the Lindbladian and Liouvillian matrix of an ensemble of N identical two-level systems in the Dicke basis.

The dynamics is given by the master equation

ρ˙=−i[H,ρ]+γE2∑nLJ−,n[ρ]+γD2∑nLJz,n[ρ]+γP2∑nLJ+,n[ρ]+γCE2LJ−[ρ]+γCD2LJz[ρ]+γCP2LJ+[ρ],

where the local rates act on each two-level system n and the collective rates act on the collective spin operators. Thanks to the permutational symmetry, the density matrix lives in a space of dimension O(N2) instead of 2N.

Arguments

  • N (Integer): The number of two-level systems.

  • hamiltonian (QuantumObject): A Hamiltonian in the Dicke basis. The matrix dimensions are (nds, nds), with nds being the number of Dicke states. The Hamiltonian can be built with the operators given by the jspin functions.

  • emission (Real): Incoherent emission coefficient (also nonradiative emission). (default: 0.0).

  • dephasing (Real): Local dephasing coefficient. (default: 0.0).

  • pumping (Real): Incoherent pumping coefficient. (default: 0.0).

  • collective_emission (Real): Collective (superradiant) emission coefficient. (default: 0.0).

  • collective_pumping (Real): Collective pumping coefficient. (default: 0.0).

  • collective_dephasing (Real): Collective dephasing coefficient. (default: 0.0).

Example

julia
using Piqs, QuantumToolbox
N = 6
jx, jy, jz = jspin(N)
system = Dicke(N, hamiltonian=jz, emission=0.5, collective_emission=1.0)
L = liouvillian_dicke(system)

Piqs.liouvillian_dicke Function
julia
liouvillian_dicke(d::Dicke)

Build the total Liouvillian using the Dicke basis.

This is the lindbladian of d plus the coherent part −i[H,⋅] if d has a Hamiltonian. The result can be given directly to QuantumToolbox.mesolve.

Returns

  • liouv (QuantumObject): The Liouvillian matrix for the system.

Example

julia
using Piqs, QuantumToolbox
N = 4
system = Dicke(N, hamiltonian=jspin(N, op="x"), collective_emission=1.0)
L = liouvillian_dicke(system)
rho0 = dicke(N, N / 2, N / 2)
sol = mesolve(L, rho0, LinRange(0, 5, 50))

Piqs.pisolve Function
julia
pisolve(d::Dicke, initial_state::QuantumObject, tlist)

Solve for diagonal Hamiltonians and initial states faster.

When both the Hamiltonian and the initial density matrix are diagonal in the Dicke basis, the dynamics reduce to the populations only, p˙=Mp, which is integrated with the permutational invariant matrix Pim.

Arguments

  • d (Dicke): The system. Its Hamiltonian, if any, must be diagonal.

  • initial_state (QuantumObject): A diagonal initial density matrix in the Dicke basis.

  • tlist (AbstractVector): The time steps to integrate over.

Returns

  • result (TimeEvolutionSol): The result of the evolution; the states are stored in result.states.

Throws

  • ArgumentError if the initial state or the Hamiltonian is not diagonal.

Example

julia
using Piqs, QuantumToolbox
N = 4
system = Dicke(N, hamiltonian=jspin(N, op="z"), emission=0.1)
rho0 = dicke(N, N / 2, N / 2)          # fully excited state
sol = pisolve(system, rho0, LinRange(0, 10, 100))
sol.states[end]

Piqs.jspin Function
julia
jspin(N::Integer; op::Union{String,Nothing}=nothing, basis::String="dicke")

Calculate the list of collective operators of the total algebra.

The Dicke basis |j,m⟩⟨j,m′| is used by default. Otherwise with "uncoupled" the operators are in a 2N space.

Arguments

  • N (Integer): Number of two-level systems.

  • op (String): The operator to return 'x','y','z','+','-'. If no operator given, then output is the list of operators for ['x','y','z'].

  • basis (String): The basis of the operators - "dicke" or "uncoupled" (default: "dicke").

Returns

  • j_alg (QuantumObject or Vector{QuantumObject}): A list of QuantumObject representing all the operators in the "dicke" or "uncoupled" basis or a single operator requested.

Example

julia
using Piqs
jx, jy, jz = jspin(4)                      # Dicke basis, 9×9 matrices
jp = jspin(4, op="+")
jz_full = jspin(4, op="z", basis="uncoupled")  # 2^4 = 16 dimensional

Piqs.spin_algebra Function
julia
spin_algebra(N::Integer, op::Union{String,Nothing}=nothing)

Create the list [sx, sy, sz] with the spin operators.

The operators are constructed for a collection of N two-level systems (TLSs). Each element of the list, i.e., sx, is a vector of QuantumObject objects (spin matrices), as it contains the list of the SU(2) Pauli matrices for the N TLSs. Each TLS operator sx[i], with i = 0, ..., (N-1), is placed in a 2N-dimensional Hilbert space.

Notes

sx[i] is σx2 in the composite Hilbert space.

Arguments

  • N (Integer): The number of two-level systems.

Returns

  • spin_operators (QuantumObject or Vector{QuantumObject}): A list of QuantumObject operators - [sx, sy, sz] or the requested operator.

                   collective_emission=0.0, collective_dephasing=0.0, collective_pumping=0.0)

Create the collapse operators (c_ops) of the Lindbladian in the uncoupled basis.

Piqs.dicke Function
julia
dicke(N::Integer, j::Number, m::Number)

Generate a Dicke state as a pure density matrix in the Dicke basis.

For instance, the superradiant state given by |j,m⟩=|1,0⟩ for N = 2, and the state is represented as a density matrix of size (nds, nds) or (4, 4), with the (1, 1) element set to 1.

Arguments

  • N (Integer): The number of two-level systems.

  • j (AbstractFloat): The eigenvalue j of the Dicke state (j, m).

  • m (AbstractFloat): The eigenvalue m of the Dicke state (j, m).

Returns

  • rho (QuantumObject): The density matrix.
source
Piqs.dicke_basis Function
julia
dicke_basis(N::Integer, jmm1::Dict=nothing)

Initialize the density matrix of a Dicke state for several (j, m, m1).

This function can be used to build arbitrary states in the Dicke basis |j,m⟩⟨j,m′|. We create coefficients for each (j, m, m1) value in the dictionary jmm1. The mapping for the (i, k) index of the density matrix to the |j, m> values is given by the function jmm1_dictionary. A density matrix is created from the given dictionary of coefficients for each (j, m, m1).

Arguments

  • N (Integer): The number of two-level systems.

  • jmm1 (Dict): A dictionary of {(j, m, m1): p} that gives a density p for the (j, m, m1) matrix element.

Returns

  • rho (QuantumObject): The density matrix in the Dicke basis.

Piqs.super_tensor Function
julia
super_tensor(to_tensor)

Tensor product of superoperators.

Given superoperators L₁, L₂, …, Lₙ acting on density matrices of the Hilbert spaces H₁, H₂, …, Hₙ, return the superoperator L acting on H₁ ⊗ H₂ ⊗ … ⊗ Hₙ such that

L[ρ1⊗ρ2⊗⋯⊗ρn]=L1[ρ1]⊗L2[ρ2]⊗⋯⊗Ln[ρn].

The subsystems may have different dimensions. This is the equivalent of super_tensor in QuTiP.

Arguments

  • to_tensor: a tuple (or vector) of SuperOperator QuantumObjects.

Returns

  • A SuperOperator QuantumObject whose dimensions are the concatenation of the dimensions of the input superoperators.

Example

julia
using Piqs, QuantumToolbox
a = destroy(2)
b = destroy(3)
L_a = liouvillian(a' * a, [a])
id_b = sprepost(qeye(3), qeye(3))
L = super_tensor((L_a, id_b))   # acts on a 2 ⊗ 3 Hilbert space

Piqs.jmm1_dictionary Function
julia
jmm1_dictionary(N::Number)

Get the index in the density matrix for this j, m, m1 value.

The (j, m, m1) values are mapped to the (i, k) index of a block diagonal matrix which has the structure to capture the permutationally symmetric part of the density matrix. For each (j, m, m1) value, first we get the block by using the "j" value and then the addition in the row/column due to the m and m1 is determined. Four dictionaries are returned giving a map from the (j, m, m1) values to (i, k), the inverse map, a flattened map and the inverse of the flattened map.

Piqs.Pim Type
julia
Pim

The Permutation Invariant Matrix class.

Initialize the class with the parameters for generating a Permutation Invariant matrix which evolves a given diagonal initial state p as:

                        dp/dt = Mp

Arguments

  • N (Integer): The number of two-level systems.

  • emission (Real): Incoherent emission coefficient (also nonradiative emission). (default: 0.0).

  • dephasing (Real): Local dephasing coefficient. (default: 0.0).

  • pumping (Real): Incoherent pumping coefficient. (default: 0.0).

  • collective_emission (Real): Collective (superradiant) emission coefficient. (default: 0.0).

  • collective_pumping (Real): Collective pumping coefficient. (default: 0.0).

  • collective_dephasing (Real): Collective dephasing coefficient. (default: 0.0).

Fields

  • N (Integer): The number of two-level systems.

  • emission (Real): Incoherent emission coefficient (also nonradiative emission). (default: 0.0).

  • dephasing (Real): Local dephasing coefficient. (default: 0.0).

  • pumping (Real): Incoherent pumping coefficient. (default: 0.0).

  • collective_emission (Real): Collective (superradiant) emission coefficient. (default: 0.0).

  • collective_dephasing (Real): Collective dephasing coefficient. (default: 0.0).

  • collective_pumping (Real): Collective pumping coefficient. (default: 0.0).

  • M (Dict): A nested dictionary of the structure {row: {col: val}} which holds non zero elements of the matrix M
