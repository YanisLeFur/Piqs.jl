Getting started ​

This page introduces the main objects of PIQSolver.jl. All the code blocks are run when the documentation is built, so the outputs shown are real.

julia
using PIQSolver, QuantumToolbox

The Dicke basis ​

For two-level systems, the collective states are labelled by the total spin   (with   for even and for odd ) and its projection   . The permutationally symmetric density matrix is block-diagonal, with one block per value of . Its dimension is the number of Dicke states:

julia
N = 4
num_dicke_states(N)
9
julia
j_vals(N)        # allowed values of j
3-element Vector{Float64}:
 0.0
 1.0
 2.0
julia
m_vals(1.0)      # allowed values of m for j = 1
3-element Vector{Float64}:
 -1.0
  0.0
  1.0

Compare with the dimension of the full Hilbert space:

julia
[(N, num_dicke_states(N), 2^N) for N in (2, 10, 20, 50)]
4-element Vector{Tuple{Int64, Int64, Int64}}:
 (2, 4, 4)
 (10, 36, 1024)
 (20, 121, 1048576)
 (50, 676, 1125899906842624)

Collective spin operators ​

jspin returns the collective spin operators   as QuantumObjects in the Dicke basis:

julia
jx, jy, jz = jspin(N)
jp = jspin(N, op=:+)
jm = jspin(N, op=:-)
size(jz)
(9, 9)

They satisfy the usual angular-momentum algebra:

julia
commutator = jx * jy - jy * jx
isapprox(commutator, 1im * jz)
true

Use basis=:uncoupled to get the same operators in the full dimensional space, which is useful to check results on small systems:

julia
size(jspin(N, op=:z, basis=:uncoupled))
(16, 16)

States ​

dicke builds the density matrix of a single Dicke state :

julia
excited = dicke(N, N / 2, N / 2)       # all two-level systems excited
ground = dicke(N, N / 2, -N / 2)       # all in the ground state
superradiant = dicke(N, N / 2, 0)      # maximal emission rate
expect(jz, excited), expect(jz, ground), expect(jp * jm, superradiant)
(2.0, -2.0, 5.999999999999999)

dicke_basis builds an arbitrary density matrix from a dictionary of   elements, here the GHZ state   :

julia
j = N / 2
ghz = dicke_basis(N, Dict((j, j, j) => 0.5, (j, -j, -j) => 0.5,
                          (j, j, -j) => 0.5, (j, -j, j) => 0.5))
tr(ghz), expect(jz, ghz)
(1.0, 0.0)

Building a system ​

A Dicke object stores , an optional Hamiltonian in the Dicke basis, and the rates of the six incoherent processes:

KeywordProcess
emissionlocal emission
dephasinglocal dephasing
pumpinglocal pumping
collective_emissioncollective (superradiant) emission
collective_dephasingcollective dephasing
collective_pumpingcollective pumping
julia
system = Dicke(N, hamiltonian=jz, emission=0.2, dephasing=0.1, collective_emission=1.0)
Dicke system
N = 4
Hilbert space dim = (9, 9)
Number of Dicke states = 9
Liouvillian space dim = (81, 81)
hamiltonian = time-independent
emission = 0.2
dephasing = 0.1
collective_emission = 1.0

lindbladian returns the dissipative part of the dynamics and liouvillian_dicke the full Liouvillian, including the Hamiltonian. Both are SuperOperators acting on the   density matrix:

julia
L = liouvillian_dicke(system)
size(L)
(81, 81)

Time evolution ​

The Liouvillian can be given to any QuantumToolbox.jl solver:

julia
rho0 = dicke(N, N / 2, N / 2)
tlist = LinRange(0, 5, 100)
sol = mesolve(L, rho0, tlist, e_ops=[jz], progress_bar=Val(false))
real(sol.expect[1, end])
-1.9125302181452875

When both the Hamiltonian and the initial state are diagonal in the Dicke basis, the dynamics only involves the populations. pisolve then solves a much smaller rate equation:

julia
sol_pim = pisolve(system, rho0, tlist)
real(expect(jz, sol_pim.states[end]))
-1.9125302255032517

Composite systems ​

super_tensor builds the tensor product of superoperators, which lets you combine the Dicke Liouvillian with the Liouvillian of another system (a cavity, another ensemble, ...), even when the two have different dimensions. See the spins in a cavity example.
